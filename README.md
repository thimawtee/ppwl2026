## Praktikum 2 | Perbedaan TailwindCSS V3 dan V4

2 perbedaan utama dari Tailwind v3 & v4 yang dapat ditemukan di play.tailwindcss.com adalah:

1. tab config, ada di v4 sedangkan di v3 tidak ada
2. di tab CSS, v4 hanya @import "tailwindcss", sedangkan di v3 ada @tailwind base, @tailwind components, dan @tailwind utilities;

## Praktikum 7 | Dark Mode

Dark mode diaktifkan dengan menambahkan class **`dark`** pada tag `<html>` dan memanfaatkan utility **`dark:`** yang disediakan oleh Tailwind CSS.

Apabila class `dark` tidak diterapkan, pengujian dark mode tetap dapat dilakukan melalui **Chrome DevTools**, dengan langkah:

**DevTools → Rendering → Emulated CSS media → prefers-color-scheme: dark**

Berikut merupakan tangkapan layar hasil pengujian dark mode tersebut:
